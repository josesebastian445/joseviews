SEO is three separate jobs that get sold as one. **Technical SEO** is making sure
Google can crawl, render and understand the site. **On-page** is making each page
unambiguously about one thing. **Off-page** is earning links and mentions.

I run all three, but I always start with the technical layer, because content
strategy on a site that takes eight seconds to load is money set on fire.

You will get a prioritised list, not a 90-page PDF. Every item has an estimated
effort and an expected impact, so you can decide what is worth doing rather than
taking my word for it.
