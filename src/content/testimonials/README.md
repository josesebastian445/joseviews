# Testimonials

This folder is intentionally empty of real entries.

Testimonials are the single highest-converting element on a services site, but
only real ones. An invented quote attributed to a real company is a legal problem
as well as an honesty one, so nothing was seeded here.

## How to add one

Create a file such as `ahmed-al-mansouri.md` in this folder:

```markdown
---
quote: What they actually said, in their words, ideally mentioning a specific outcome.
name: Full Name
role: Job Title
company: Company Name
order: 1
---
```

The testimonials section on the homepage renders itself only when at least one
entry exists, so the site looks complete either way.

## How to get them

Ask straight after you deliver something that worked, while the relief is fresh.
A message along the lines of: *"Glad that sorted it — would you mind writing two
lines I can put on my site? Happy to draft something for you to edit."*

Offering the draft roughly triples the response rate, because you have turned a
writing task into an approval task.
